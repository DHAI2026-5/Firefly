# 本地博客编辑器

给自己用的那个"不想开终端写文章，但照片要进仓库"的工具。

```bash
pnpm blog          # → http://127.0.0.1:4322（会自动打开浏览器）
```

只监听 `127.0.0.1`，不对外暴露，没有账号密码，也不需要 token。

## 它做三件事

1. 把文章写成 `src/content/posts/<日期>-<英文短横线>.md`
2. 把图片压成 avif 放进 `src/content/posts/<同名文件夹>/`
3. 「发布」= 存盘 + `git commit` + `git push`（只提交这一篇）

## 图片

- 拖进图片区、点「选择图片」、或者直接 **Ctrl+V 粘贴截图** 都行
- 服务端用 sharp 处理：铺平 EXIF 方向、最长边 1600、`avif quality 80`
- 手机拍的 8MB 原图 → 通常 150~400KB
- 落地文件：`src/content/posts/<文章>/1.avif`
- 正文里插入的写法：`![说明](./<文章>/1.avif)`
- 勾选几张再点「插入组图」，会生成主题认识的块：

```
[grid]
![图片1](./2026-10-12-my-post/1.avif)
![图片2](./2026-10-12-my-post/2.avif)
[/grid]
```

`[grid]` 必须独占一段、`[/grid]` 收尾，列数由图片数量自动算（1~4 列）。

## 发布规则

- 只 `git add` 这一篇文章和它的图片文件夹，别的改动不会被带上
- 你已经暂存的其他文件也不会被一起提交
- 提交信息：`content: 新增文章《标题》` / `content: 更新文章《标题》`
- push 失败只报错，不自动合并、不 force；本地提交已经在了，修好网络再手动 `git push` 即可
- 内容和上次完全一样时不会产生空提交

## 文件名为什么会被锁

文件名 = 文章的 id。一旦有图片或者已经保存过，改文件名就等于换文章，会留下孤儿图片，所以锁定。想改名就把图片删掉、`新文章` 重来一次。

## 草稿

- 输入的内容自动存 localStorage，关掉页面再打开会恢复
- 保存/发布成功后自动清除
- 注意：草稿只存在这个浏览器里

## 常见问题

| 现象 | 原因 |
|---|---|
| 提示 `没有找到 sharp` | 先跑一次 `pnpm install` |
| 端口被占用 | `BLOG_EDITOR_PORT=4399 pnpm blog` |
| 本地预览的封面没有灰底占位 | 「保存后更新 LQIP」勾上，或手动 `pnpm lqips` |
| 本地预览打不开 | 另开一个终端跑 `pnpm dev`（4321） |
| 图片传上来但没进正文 | 图片是先进磁盘，点图片上的「插入」才写进正文 |

## 不做什么

- 不管 `pnpm dev` / 构建 / 部署（那是 Actions 的事）
- 不碰相册 `public/gallery/`、不碰 `_frontmatter.json`
- 不做富文本所见即所得
- 不做多人协作、公网访问、手机远程写
